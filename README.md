# MS-COCO Image Captioning Project

## 📌 Overview
This project is part of the CSE 440 Statistical Natural Language Processing course. The goal is to build an Encoder-Decoder architecture to generate captions for images using the MS-COCO dataset.

## 🛠 Planned Roadmap
- [ ] Phase 1: Comparison of LSTM vs GRU Decoders.
- [ ] Phase 2: Implementation of Teacher Forcing.
- [ ] Phase 3: Global Attention Mechanisms (Additive, Dot-Product, Scaled Dot-Product).
- [ ] Bonus: Metaheuristic optimization for Attention weights.

## 🏗 Project Structure
- `src/`: Source code for models and data processing.
- `notebooks/`: Experiments and Colab integration.
- `configs/`: Configuration files for experiments.
- `.github/workflows/`: CI/CD automation.
